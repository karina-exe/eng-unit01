## 𖹭.ᐟ.ᐟTUMBLR THEME: Addition of minor elements on @natsyme's original code for aesthetic purposes

Theme’s name: “UNIT 01”, inspired by Neon Genesis Evangelion. The original theme has an overall layout that pleases me, as well as interesting functions, such as personalized favicon, tag icons and cursor. However, I felt that something was missing - something that could personify my aesthetic vision. Thus, I added the following elements: hovering on the sidebar links, multiple background options and right click disable alongside a pop up text (a symbolic writing as an embodiment of the theme’s concept).
